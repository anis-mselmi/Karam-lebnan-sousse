# Karam Lebnan

Site vitrine du restaurant libanais Karam Lebnan (Sousse). Vite + React + TypeScript.

## Prerequisites

Node.js 18+ and npm.

## Run

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Build

```bash
npm run build     # output in dist/
npm run preview   # preview the production build
```
